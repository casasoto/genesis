# Testing LocksmithPrep

## Quick Commands

```bash
# Run all 189 unit tests
npx vitest run

# Run tests in watch mode
npm run test

# Lint
npm run lint

# Type check
npm run typecheck

# Production build (generates PWA service worker)
npm run build

# Start dev server (default port 5173)
npm run dev
```

## UI Verification Checklist

After starting the dev server at `http://localhost:5173/`:

1. **Disclaimer banner** (yellow, top of page): "LocksmithPrep is a study aid only. It does not guarantee passing any exam. Always seek supervised hands-on practice and follow all applicable laws."
2. **Header**: "LocksmithPrep" in blue with lock emoji, subtitle "ALOA Locksmith Exam Preparation"
3. **Navigation tabs** (6 total): Dashboard, Lessons, Practice Exams, Flashcards, Study Plan, AI Tutor
4. **Dashboard** (default view): "Welcome to LocksmithPrep" heading, 3 cards (Study Progress, Exam Readiness, Study Streak)
5. **Non-dashboard tabs**: Show placeholder "Module coming in MVP. Architecture is ready."
6. **Footer**: "LocksmithPrep v0.1.0-alpha — Not affiliated with ALOA. For study purposes only."
7. **Dark mode**: Dark slate background (#020617), light text
8. **No console errors** during navigation

## Architecture Notes

- **Stack**: React 19 + TypeScript + Vite 8 + Tailwind CSS 4 + Dexie.js + vite-plugin-pwa
- **Test framework**: Vitest with jsdom environment
- **8 test files** covering: LLM adapter, AI tutor, exam engine, study planner, flashcards/SM-2, content pipeline, notifications, feature flags
- **UI is a shell** — tabs switch content via React state, no routing library yet
- **PWA service worker** is generated by vite-plugin-pwa (Workbox) during build

## Common Issues

- If `npm run dev` fails, ensure `npm install` was run first
- The app has no backend — all logic is client-side
- No CI is configured on the repo; tests must be verified locally
- Feature flags control which exam levels are enabled; disabled features don't appear in nav

## Devin Secrets Needed

None — this app runs entirely locally with no external API calls required for testing.
